NAME

tenda-n300 - control a Tenda N300 wireless router from your terminal. No browser needed.

SYNOPSIS

tenda-n300 [--ip addr] [--password pass] [--profile name] [--json] command [args]

Every router lives in a profile. Add one, run any command against it, and the tool remembers which network you are on and picks the right profile automatically.

INSTALLATION

One line, no Go toolchain required. Downloads the pre-built binary for your OS and installs it to /usr/local/bin.

Build from source
git clone https://github.com/kakashy/tenda-n300.git && cd tenda-n300 && ./build.sh
Go install
go install github.com/kakashy/tenda-n300@latest
Manual build
go build -ldflags="-s -w" -o tenda-n300 . && sudo mv tenda-n300 /usr/local/bin/

QUICK START

Three commands from a blank machine to a blocked device:

quick start 
$ tenda-n300 discover
found Tenda router at 192.168.0.1 (N300)
save as profile? [y/N]: y
profile 'default' saved, password: admin
$ tenda-n300 profile add home --ip 192.168.0.1 --password admin
profile 'home' added and set as default
$ tenda-n300 devices

The password never touches disk; it goes straight into your OS keyring (macOS Keychain, Linux Secret Service, Windows Credential Manager).

DESCRIPTION

tenda-n300 talks to the router's own web API (goform) the same way the admin page does, but from a shell. Batch it, script it, pipe it, and automate it; the vendor web UI becomes optional.

  • devices: every connected and blocked device on the network
  • block / unblock: cut or restore internet by MAC address
  • wifi: view or change SSID, password, channel, encryption
  • status: totals: online, offline, blocked
  • reboot: restart the router from the terminal
  • discover: sweep the LAN for Tenda routers and save them as profiles
  • backup / restore: save and reload router configuration
  • syslog: export the router's system log
  • profile: multiple routers (home, work), switched by flag or by network fingerprint
  • --json: machine-readable output for scripts

OPTIONS

--ip addr
Router IP address. Overrides config and profiles.
--password pass
Router admin password. Overrides config and profiles. Use with care on shared shells.
--profile name
Router profile name. Overrides auto-detection.
--json
Emit JSON instead of tables. For scripts and pipes.
--ssid name
New WiFi SSID (with the wifi command).
--wifi-password pass
New WiFi password (with the wifi command).
--channel n
New WiFi channel, 1–11 (with the wifi command).
--encrypt mode
New encryption mode, e.g. WPA2PSK/AES (with the wifi command).

FILES

    

      
~/.config/tenda-n300/config.json

      
Profiles, default profile, and the network fingerprint cache. Created with 0700 permissions.

      
OS keyring, service tenda-n300

      
Passwords, keyed per profile (password for the default profile, password:<name> for named ones). Never in plaintext on disk.

DISCLAIMER

    

      This tool interacts with the router's internal web API. It is not officially
      supported by Tenda, and Tenda may change or disable the endpoints it relies on at any
      time. Use it at your own risk: it may break with a firmware update, and any damage to
      the router, its configuration, or your network is your responsibility.
    

    

      All communication with the router is over plain HTTP, with no encryption.
      Never use this tool on a network you do not trust, and be aware that credentials and
      commands travel unencrypted between the machine running it and the router.
    

    

      This project is a personal, unofficial tool. It comes with no warranty, express or
      implied, and the author accepts no liability for any loss or damage arising from its
      use. This includes, but is not limited to: a router that stops working, a WiFi
      network that goes down, or a factory reset you did not intend.
    

    

      Factory reset wipes every router setting. Back up your configuration first with
      backup, and confirm you are issuing the command against the right profile.
